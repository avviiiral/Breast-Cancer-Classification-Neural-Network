# 🧠 Breast Cancer Classification using Neural Network

This project focuses on **classifying breast cancer as Malignant or Benign** using a **simple Neural Network (NN)**. The model is trained on structured medical data and demonstrates how deep learning can be applied to healthcare-related classification problems.

---

## 📌 Project Overview

* Built a **Neural Network from scratch** using Python
* Used real-world breast cancer dataset
* Performed data preprocessing and model training
* Evaluated model performance using accuracy

---

## 📊 Dataset

* The dataset contains medical attributes related to breast cancer.
* Target column represents:

  * **0 → Benign**
  * **1 → Malignant**

## ⚙️ Steps Performed

2. Data preprocessing (handling nulls, scaling)
3. Splitting data into training and testing sets
4. Building a simple Neural Network
5. Training the model
6. Evaluating accuracy and performance

## ▶️ How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/avviiiral/Breast-Cancer-Classification-with-a-simple-Neural-Network-NN-.git
```

2. Navigate to the project directory

```bash
cd Neural_Network_Breast_Cancer
```

3. Install required libraries

```bash
pip install numpy pandas matplotlib seaborn scikit-learn tensorflow
```

4. Open the notebook

```bash
jupyter notebook
```

5. Run `brest cancer neural network.ipynb`
